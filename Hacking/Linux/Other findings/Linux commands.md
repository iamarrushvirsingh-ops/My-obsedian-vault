
# SSH

- Used to connect to another machine 
	`yourusername@targetmachine`

# VIM
- After you are done doing your changes . 
- Press esc 
- And then type `:wq` to write + quit .

# SHRED []

- It makes the file contents unreadable .

# CP
- Copies a file 

# RM 
- If you run this on a directory with a recursive flag then it will delete the whole dir . 
- Used to delete files . 

# LN 
- Creates a link to the file or dir you want , like a shortcut to it , saves space and keeps things updated . 

# USERADD 
- Use this command to add a user to the system 
- Following this you should add the desired username and now u have a new user !

# ADDUSER 
- Using this command you can asses and change parameters for a user . 
- Like passwords and all 
# SU 
- This is used to switch users . 
- You can use exit to exit a user . 

# PASSWD 
- You can use this command to add a password . 
- You can do this on users too .
- You need to specify the user then whom you are changing the password for . 
- If you dont specify the user it will change the passwd for the current user . 

# APT
- Debian based packet manager . 
- Its best practice to update , before downloading any new package .

# FINGER  
- Its used to inspect a user . 

# WHATIS 
- Gives you a very basic idea of what the specified command is about . 

# WHICH 
- Lets you know the location of a binary 

# WHEREIS 
- Lets you know all the locations of a binary keyword/name . 

# WGET 
- Used to fetch info or things from the internet . 
- Automatically saves a file .

# CURL 
- Same as wget . 
- You need to allocate the output to a file . 

# ZIP 
- Used to zip a file so it doesn't take much space . 
- Specify the zip file that will be created and then the target file name .
	# UNZIP 
	- Used to unzip a zipped file . 

# LESS 
- Similar to cat but lets you see one page at a time so the output is readable .

# HEAD 
- Used to see the head of a file . 

# Tail 
- Used to see the bottom of a file . 

# CMP
- Used to compare to a file .
- Specify the 2 files and it will let you know what is the difference between them .

# DIFF
- Like cmp tells us that there is a difference , diff tells us what the difference is . 

# SORT
- Pipleline it to any command / file and it will sort its contents alphabetically . 

# FILE 
- Specify the starting location and then using the name flag ,specify name of the file you want to find . 
- You can find hidden or executable files also . 
# CHMOD 
- Used to change permissions of a file . 
- Like making it only read or executable . 

# CHOWN 
- Used to change ownership of a file . 

# IP ADDRESS
- Same as ifconfig .
- Just better 

# GREP 
- Filters out the specified text from a huge bundle of text .
