# File system 

- /root : The home dir of all powerful root users .
- /etc : Contains the linux config files . It contains instructions about how programs should start . 
- /home : Home dir 
- /mnt : When other filesystems are mounted to the filesystem. 
- /media : Where cds and usbs are attached or mounted to the filesystem . 
- /bin : Where application binaries are stored . 
- /lib : Where you will find libraries . 


# Some basic commands 

- pwd : where you are ( present dir )
- whoami : what user you are logged in as .
- cd : change dir 
	-  `..` this moves you up a level 
	- `../..` this moves you up 2 levels and so on . 
- ls : list 
	- `-a` shows hidden files 
	- `-l` lists the output in a good way .
- --help : this will give you a idea about the command 
- NOTE : Its standard to use -- before word flags and - before single char flags .
- man : this command is used to get a small manual description  of the cmd just like help
	-  Eg : `man example_command 
- locate : this is used to find a keyword in the linux file system .
