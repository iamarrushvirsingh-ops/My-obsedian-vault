
#repository
-  A repository is a project containing files and folders .
#branch
- A branch is like a parallel version of your repository .
- If you want to add changes or features to a file , you will make a branch of the repo u want to make changes to , and then you can start making changes to that branch without affecting the main branches code . 
#commits
- Similar to saving changes in a file , commit is saving changes to one or more files in a branch . 
- Git assigns each commit a specefic id that states 
	- Who made that commit .
	- When the commit was made .
	- The specific change .
- It is advised to add a commit message to commits that describes the changes .
- You can create a co-author on a commit you are commiting .
- You just need to go to the repo and branch in which u want to commit and then you can add file or upload file as a commit , and then mention the commit description and name . 
- After this you will just commit the changes , and your part is done .
#pullrequest
- Pull request is basically a proposal sort presenting your commit to be added to the main branch .
- If the commit is considered to be relevant or good enough , then the pull request is accepted . 
#merge
- A merge adds your pull request and branch changes to the main branch .
